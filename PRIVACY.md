# Privacy policy

_Last updated: 28 October 2026_

OpenAide is an open source assistant app. It has no account system of its
own, no analytics, no ads and no crash reporting. The people who make
OpenAide never receive your data.

## Where your data goes

Your data goes only to the services **you** choose to connect:

| You connect | What is sent there |
| --- | --- |
| An Open WebUI server | Your chats, files, notes, voice and everything else you use in the app. Chats are stored on that server. |
| An AI provider (OpenRouter, Anthropic, OpenAI, GitHub Copilot) | The messages and files of chats that use that provider. |
| An email account (IMAP/SMTP) | The app reads and sends email directly with your provider. |
| Web search (DuckDuckGo, Brave, Tavily or your own SearXNG) | The search words when the assistant searches the web. |
| MCP or tool servers you add | What the assistant sends to those tools. |
| Hugging Face | Requests to search and download models that run on your phone. |
| GitHub | A check for new versions of the app (no personal data). |

Each of those services has its own privacy policy.

## What stays on your phone

- Sign-ins, API keys and passwords, in Android's encrypted storage. They
  are not included in phone backups.
- Chats made without a server, models downloaded to the phone, and a
  cache of recent server data so the app opens offline.

Uninstalling the app deletes all of it.

## Phone permissions

| Permission | Used for |
| --- | --- |
| Microphone | Voice calls, dictation and note recording, only while you use them. |
| Contacts | Finding who you mean when you ask the assistant to call or text someone. Contacts are looked up on the phone. The chat gets the name you asked about and, when several contacts match, their names and the last two digits of each number so you can pick. Whole numbers and other contacts stay on the phone. |
| Approximate location | Only if you turn it on, to tell the assistant roughly where you are (for example for the weather). |
| Notifications | Telling you when a reply or message arrives. |
| Install apps | Installing updates of OpenAide itself (not in store versions). |
| Alarms, start at boot | Timers and alarms you ask for, and reply checks after a restart. |

## Children

OpenAide is not meant for children under 13.
