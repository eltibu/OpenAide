Pick how you use it

Bring your own server, or no server at all.

The first screen asks how you want to start. You can add the other options later in Settings.

Open WebUI

Connect your server

Enter an address like https://chat.example.com and sign in with a password, an API key, or your server's sign-on page. Chats, models, tools and knowledge stay on the server, so the phone and the web always match.

AI provider

Sign in and chat

Sign in to OpenRouter or GitHub Copilot, or paste a Claude or OpenAI key. You still get tools, skills and MCP servers, straight from the phone.

On-device

Run it offline

Download a small model from Hugging Face once. It runs on the phone with llama.cpp, so nothing leaves your device and it works in airplane mode.

Everything it does

The whole of Open WebUI, rebuilt natively for your phone.

Every screen, button and setting from the web UI, plus the things only a phone can do. When you add a model or tool on your server, it shows up in the app without an update.

Install in about a minute

Get it from GitHub.

OpenAide isn't on Google Play yet. Every release is built automatically from the public source code.

  1. Download

    On your phone, open the latest release and tap the OpenAide .apk under Assets.

  2. Open the file

    Tap the download notification, or find the file in Downloads.

  3. Allow the install

    The first time, Android asks: tap Settings, turn on Allow from this source, go back and tap Install.

  4. Open OpenAide

    Pick how you want to use it: your server, an AI provider, or a model on the phone.

If Play Protect warns you, tap More details, then Install anyway. It shows this for any app that doesn't come from the Play Store. Needs Android 9 or newer.
